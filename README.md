# Keepercent — study log

Public site for Keepercent, a handball goalkeeper scouting app for iPhone and iPad.

- `index.html` is the Spanish study log, served at https://tomioliveres.github.io/keepercent/.
- `privacy.html` is the app's privacy policy and `support.html` its support page (English and Spanish), the URLs the App Store listing uses.
- The app's source code is private.
